# homebrew-hx

Homebrew tap by bgzo.

## Install

```bash
brew tap bgzo/hx
brew install sqlit
```

Or:

```bash
brew install bgzo/hx/sqlit
```

## Formulae

| Formula | Description |
|---------|-------------|
| [sqlit](https://github.com/Maxteabag/sqlit) | User-friendly TUI for SQL databases |
